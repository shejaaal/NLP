# 🕵️ Crime Classification and IPC Mapping using NLP & Machine Learning

## 📝 Project Overview
Developed an automated system using NLP and machine learning to classify crimes and map them to relevant IPC (Indian Penal Code) sections.

## ⚙️ Approach
- Built a data preprocessing pipeline to clean and vectorize text using TF-IDF
- Trained a machine learning model to classify crime categories based on textual data
- Addressed class imbalance and evaluated performance using accuracy and other relevant metrics

## 📈 Outcomes
- Functional model for crime classification from text
- IPC section mapping enabled through predicted categories
- Documented codebase for easy replication and future enhancement
- Suggestions included for improving performance and handling data challenges

- `crime_classification.ipynb`: Jupyter/Colab notebook with full implementation
- `report.pdf`: Mini project report
